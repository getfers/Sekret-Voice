# Sekret Voice

Sekret Voice меняет голос с микрофона в реальном времени на ПК с Windows. Обработанный звук можно направить в наушники или передать через виртуальный кабель в Discord, OBS и другие приложения. В интерфейсе есть 50 пресетов с поиском, усиление микрофона, измеритель уровня и коррекция высоты по выбранной гамме.

Готовый `SekretVoice.exe` для Windows x64 можно скачать [в GitHub Releases](https://github.com/getfers/Sekret-Voice/releases/latest).

## Запуск из исходников

Нужны Windows 10 или 11 (x64), Python 3.12 (x64) с поддержкой Tcl/Tk и включённый в настройках Windows доступ настольных приложений к микрофону. Откройте PowerShell и выполните команды:

```powershell
git clone https://github.com/getfers/Sekret-Voice.git
cd Sekret-Voice
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Настройка звука

1. В блоке **1. Ваш микрофон** уже выбран системный микрофон. При необходимости выберите другой.
2. В блоке **2. Куда отправлять голос** приложение автоматически выбирает обнаруженный виртуальный кабель. Если кабеля нет, используется системное устройство воспроизведения.
3. Выберите пресет и нажмите **Включить голос**. Пресет меняется одним щелчком. По умолчанию включён эффект «Робот». Сочетание `Ctrl+F` переводит фокус в поиск, а `Enter` применяет первый найденный пресет.
4. Для пробы выберите **Наушники для прослушивания** и нажмите **Прослушать себя**. При выключенном основном выходе голос идёт только в выбранные наушники. При включённом основном выходе кнопка добавляет отдельное прослушивание. Если основной выход уже направлен в наушники, голос слышен через него.
5. Настройте **Громкость** от −18 до +24 дБ. Индикатор показывает уровень микрофона после усиления. Если уровень часто достигает 0 дБ, уменьшите усиление.

Оба выхода получают сигнал из цепочки выбранного эффекта. Приложение не подмешивает отдельную дорожку исходного микрофона. Это касается и пресетов с эхом, хорусом и реверберацией.

### Подключение VB-CABLE

Установите драйвер [VB-CABLE](https://vb-audio.com/Cable/) и следуйте инструкции производителя. Запустите Sekret Voice после установки драйвера.

| Где выбрать | Устройство |
| --- | --- |
| Sekret Voice → **1. Ваш микрофон** | Физический микрофон |
| Sekret Voice → **2. Куда отправлять голос** | **CABLE Input**, устройство воспроизведения |
| Discord / OBS → микрофон или источник захвата | **CABLE Output**, устройство записи |
| Sekret Voice → **Наушники для прослушивания** | Физические наушники, если нужно локальное прослушивание |

Если устройство подключили после запуска, остановите обработку и нажмите **Обновить**. Устройства отображаются под системными именами. Приложение пробует Windows WASAPI, затем совместимые варианты DirectSound и MME. При необходимости оно открывает вход и выход отдельно и согласует их частоты. WDM-KS и служебные дубли скрыты.

В WASAPI приложение сначала пробует буфер на 64 сэмпла и при повторяющихся перебоях автоматически повышает запас. Строка состояния показывает задержку устройств по данным PortAudio с учётом буфера при раздельном подключении. Полная задержка зависит от драйвера, нагрузки и пресета. Сдвиг высоты использует короткий буфер, а чистое «Эхо» начинает звучать с первого намеренного повтора.

### Auto-Tune

Включите Auto-Tune, выберите тонику и гамму. Доступны хроматическая гамма, мажор, минор и обе пентатоники. При хроматической гамме доступны все 12 нот, поэтому тоника не меняет результат. На 100% высота быстрее и сильнее подводится к разрешённой ноте. На низкой силе переходы плавнее и сохраняют больше исходной интонации. Корректор рассчитан на один голос и применяет музыкальную настройку перед транспонированием пресетом. Для коррекции без транспонирования выберите пресет, который не сдвигает высоту, например «Радио».

## Сборка Windows .exe

Выполните команды в той же папке и виртуальной среде:

```powershell
.\.venv\Scripts\python.exe -m pip install "pyinstaller>=6.16,<7"
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm SekretVoice.spec
```

Готовый файл находится в `dist\SekretVoice.exe`. Он включает Python, Tcl/Tk, зависимости интерфейса, PortAudio и графику. Сторонние виртуальные аудиодрайверы устанавливаются отдельно. Для повторной сборки после изменения зависимостей можно добавить `--clean`.

## Проверка и устройство проекта

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

- `main.py` содержит интерфейс CustomTkinter, стартовую анимацию и каталог.
- `audio_devices.py` группирует варианты одного устройства и выбирает системный микрофон и виртуальный кабель.
- `audio_engine.py` согласует потоки через SoundDevice и PortAudio и отправляет обработанный звук на выбранные выходы.
- `dsp.py` обрабатывает монофонический сигнал через NumPy и SciPy. В нём реализованы сдвиг высоты через перекрывающиеся окна, коррекция нот через оценку основного тона, формантные резонаторы, фильтры, модуляция, насыщение, хорус, эхо и реверберация.
- `presets.py` содержит 50 настроек эффектов. Каждая карточка ссылается на одну настройку.
- `logo.png` — исходный логотип, `sekret.ico` — значок приложения из квадратной части логотипа.

Звук обрабатывается локально. Приложение не записывает аудио и не отправляет его в сеть.

Справочные материалы по сборке и звуку — [CustomTkinter](https://customtkinter.tomschimansky.com/documentation/packaging/), [PyInstaller](https://pyinstaller.org/en/stable/spec-files.html) и [SoundDevice](https://python-sounddevice.readthedocs.io/en/latest/api/streams.html).
