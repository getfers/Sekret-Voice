# Sekret Voice

Sekret Voice меняет голос с микрофона в реальном времени на ПК с Windows. Обработанный звук можно направить в наушники или передать через виртуальный кабель в Discord, OBS и другие приложения. В интерфейсе есть 50 пресетов с поиском, усиление микрофона, измеритель уровня и коррекция высоты по выбранной гамме.

## Запуск из исходников

Нужны Windows 10 или 11 (x64), Python 3.12 (x64) с поддержкой Tcl/Tk и включённый в настройках Windows доступ настольных приложений к микрофону. Откройте PowerShell и выполните команды:

```powershell
git clone https://github.com/getfers/Sekret-Voice.git
cd Sekret-Voice
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Настройка звука

1. В **Input** выберите свой микрофон. В **Output** выберите устройство, которое должно получать обработанный сигнал. Для прослушивания через основной выход подойдут наушники. Для передачи в другую программу выберите виртуальный кабель.
2. Выберите устройства с одинаковым звуковым API из списка. Предпочтительный вариант для Windows — **Windows WASAPI**.
3. Нажмите **Запустить** и выберите пресет. Карточки применяются сразу. **Сбросить** вернёт оригинальный тембр, сохранив значения Gain и Auto-Tune. Сочетание `Ctrl+F` переводит фокус в поиск, а `Enter` применяет первый найденный пресет.
4. Настройте **Gain** в диапазоне от −18 до +24 дБ. Измеритель показывает входной RMS после усиления, в dBFS. Если голос постоянно упирается в 0 dBFS, уменьшите усиление.
5. Для отдельного локального прослушивания выберите **Наушники** и нажмите **Monitor вкл.** Основной выход продолжит получать звук. Если сам **Output** уже направлен в наушники, голос слышен без Monitor.

### Подключение VB-CABLE

Установите драйвер [VB-CABLE](https://vb-audio.com/Cable/) и следуйте инструкции производителя. Запустите Sekret Voice после установки драйвера.

| Где выбрать | Устройство |
| --- | --- |
| Sekret Voice → **Input** | Физический микрофон |
| Sekret Voice → **Output** | **CABLE Input**, устройство воспроизведения |
| Discord / OBS → микрофон или источник захвата | **CABLE Output**, устройство записи |
| Sekret Voice → **Наушники** | Физические наушники, если нужно локальное прослушивание |

При отсутствии устройства нажмите **Обновить**. Если новый драйвер или подключённое устройство всё ещё отсутствует в перечне, перезапустите приложение. Если звук прерывается, остановите поток, увеличьте **Аудиобуфер** с 256 до 512 сэмплов и запустите его снова. Для меньшей задержки попробуйте 128 сэмплов. Значение в строке состояния показывает задержку основного потока, сообщённую PortAudio. Pitch Shift и Auto-Tune используют дополнительный короткий буфер, а эффекты эха и реверберации намеренно добавляют отражения.

### Auto-Tune

Включите Auto-Tune, выберите тонику и гамму. Доступны хроматическая гамма, мажор, минор и обе пентатоники. При хроматической гамме доступны все 12 нот, поэтому тоника не меняет результат. На 100% высота быстрее и сильнее подводится к разрешённой ноте. На низкой силе переходы плавнее и сохраняют больше исходной интонации. Корректор рассчитан на один голос и применяет музыкальную настройку перед транспонированием пресетом. Для коррекции без транспонирования используйте оригинальный голос или пресет без эффекта «Тон».

## Сборка Windows .exe

Выполните команды в той же папке и виртуальной среде:

```powershell
.\.venv\Scripts\python.exe -m pip install "pyinstaller>=6.16,<7"
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm SekretVoice.spec
```

Готовый файл находится в `dist\SekretVoice.exe`. Он включает Python, Tcl/Tk, зависимости интерфейса, PortAudio и графику. Сторонние виртуальные аудиодрайверы устанавливаются отдельно. Для повторной сборки после изменения зависимостей можно добавить `--clean`.

## Проверка и устройство проекта

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

- `main.py` содержит интерфейс CustomTkinter, стартовую анимацию и каталог.
- `audio_engine.py` открывает потоки через SoundDevice и PortAudio, маршрутизирует выход и Monitor.
- `dsp.py` обрабатывает монофонический сигнал через NumPy и SciPy. В нём реализованы сдвиг высоты через перекрывающиеся окна, коррекция нот через оценку основного тона, формантные резонаторы, фильтры, модуляция, насыщение, хорус, эхо и реверберация.
- `presets.py` содержит 50 настроек эффектов. Каждая карточка ссылается на одну настройку.
- `logo.png` — исходный логотип, `sekret.ico` — значок приложения из квадратной части логотипа.

Звук обрабатывается локально. Приложение не записывает аудио и не отправляет его в сеть.

Справочные материалы по сборке и звуку — [CustomTkinter](https://customtkinter.tomschimansky.com/documentation/packaging/), [PyInstaller](https://pyinstaller.org/en/stable/spec-files.html) и [SoundDevice](https://python-sounddevice.readthedocs.io/en/latest/api/streams.html).
